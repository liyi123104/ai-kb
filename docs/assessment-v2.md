## 四、剩余问题

### P1 · 缺 rerank

Top-1 只有 19/30；计划书 E2 一直未做，需 ollama pull bge-reranker-v2-m3

**建议**：拉模型后接上，观察 Top-1 与准确率

### P1 · 实验集合占 60% 磁盘

5 个 exp-* 集合共 49,728 片，向量库 1,021 MB 里大半是它们

**建议**：加 scripts/cleanup_experiments.py，或确认实验数据已归档后删掉

### P1 · 鉴权默认关闭

本机方便，但一旦部署到公网而忘了设置，仍然等于开放

**建议**：部署文档里把「设置 AUTH_TOKEN」写成必做步骤；或在检测到非本机访问时警告

### P2 · 无并发与端到端测试

30 个用例都是串行单请求；浏览器交互靠人工截图验证

**建议**：加并发上传用例、Ollama 宕机用例、Playwright 端到端

### P2 · 容器内生成慢 2–4 倍

Docker Desktop 的 WSL2 与宿主抢 CPU，非代码问题

**建议**：演示用本机模式；Linux 服务器上复测

### P2 · 单用户设计

无多租户、无配额、无上传频率限制

**建议**：若对外开放需加限流与用户隔离
