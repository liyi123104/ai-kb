# 演示视频脚本（T5.3，3 分钟）

计划书要求：**上传 → 提问 → 展示出处 → 展示历史 → 介绍架构**，时长 3 分钟左右，画面清晰、声音可听。

## 录制前准备（10 分钟）

```powershell
cd D:\ai-kb

# 1) 确认模型在跑
ollama list

# 2) 起后端（窗口 A，保持开着）
.\.venv\Scripts\python.exe -m app.main

# 3) 起前端（窗口 B）
#    装了 node_modules 就用 Vue 界面；没装就用 Streamlit 顶
cd D:\ai-kb\web; npm run dev            # http://localhost:5173
# 或
.\.venv\Scripts\python.exe -m streamlit run ui_streamlit.py   # http://localhost:8501
```

准备三个演示素材（放到桌面即可）：

- 一份 **PDF**（比如 `materials/rag-lewis-2020.pdf`，19 页，上传快）
- 一份 **Markdown**（随手写 10 行笔记，演示多格式）
- 一份 **不支持的文件**（如 `test.exe` 改名即可，演示 400 报错）

录制工具：`Win + G`（Xbox Game Bar）或 OBS。分辨率 1920×1080，浏览器缩放 100%，
终端字号调到 16 以上（录出来才看得清）。

## 录制时的坑

1. **冷启动慢**：第一次提问要加载 7B 模型（8 秒左右），先随便问一句预热，再正式录。
2. **别录到密钥**：`.env` 里有 `DEEPSEEK_API_KEY`，录屏前关掉终端里的 `cat .env`。
3. **出声**：先试录 10 秒回放，确认麦克风有声音，音量不要爆音。
4. **一次录成比剪辑省事**：提前把三个问题打在记事本里，直接复制粘贴提问，避免打字卡顿。
